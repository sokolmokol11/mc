# Крипто-симулятор торговых ботов

11 ботов торгуют **виртуальными** деньгами ($1000 у каждого) на **настоящих** ценах Bybit, 24/7.
Реальные деньги не участвуют, ключи API и регистрация на бирже не нужны.

## Как запустить на сервере (Linux, 24/7)

```bash
cd ~/mc && git pull
cd trading_sim && bash install_server.sh
```

Скрипт поставит библиотеки, придумает пароль, проверит связь с Bybit, создаст службу `trading-sim`
(работает 24/7, перезапускается сама) и напишет адрес страницы. Если Bybit с сервера не открывается —
впиши SOCKS5-прокси в `.env` (строка `SIM_PROXY=socks5h://логин:пароль@адрес:порт`) и запусти скрипт ещё раз.

- журнал вживую: `journalctl -u trading-sim -f`
- обновить после новой версии в GitHub: `bash update_server.sh`
- пароль: `cat .env`

## Бэктест: проверить стратегии на прошлом месяце (не ждать)

```bash
cd ~/mc/trading_sim
python3.11 backtest.py --serve            # последние 30 дней
python3.11 backtest.py --days 90 --serve  # последние 90 дней
python3.11 backtest.py --days 90 --bots pumps --serve  # только шортисты пампов v1 и v2
```

Скрипт скачает с Bybit историю (первый раз 5–15 минут, потом 12 часов берёт из кэша), прокрутит её через всех
ботов за пару минут и покажет таблицу итогов. С `--serve` откроется такая же страница, как у живого
симулятора, на порту 8001: графики сделок, журнал решений, отчёт. Если порт закрыт: `firewall-cmd --add-port=8001/tcp`.
Отчёт сохраняется в `data/backtest_report_*.md` — его можно прислать Claude для разбора.

Живой симулятор при этом продолжает работать, бэктест его не трогает.

Что бэктест упрощает: монеты, которые уже убрали с биржи, в истории отсутствуют; внутри 15-минутной свечи цена
идёт по схеме открытие → экстремум → экстремум; проскальзывание фиксированное. Меньше 30 сделок у бота — результат почти случайный.

## Как запустить (Windows)

1. Установи Python: https://www.python.org/downloads/
   На первом экране установщика **обязательно** поставь галочку **«Add python.exe to PATH»**.
2. Распакуй архив в любую папку, например `C:\trading_sim`.
3. Дважды кликни **run.bat**. Откроется чёрное окно, а через пару секунд — страница в браузере.
4. Если страница не открылась сама — открой в браузере **http://localhost:8000**

Пока окно открыто, боты работают. Закрыл окно — остановились.
При следующем запуске они продолжат с того же места (всё хранится в папке `data`).

**Чтобы работало 24/7:** Параметры Windows → Система → Питание → «Переводить в спящий режим» → **Никогда**.

**Начать всё заново:** закрой окно и удали папку `data`.

## Боты

**Основные стратегии** (подробный разбор — в документе «Стратегии для крипто-симулятора»):

| Бот | Свечи | Идея |
|---|---|---|
| Шортист пампов v2 | 15 мин, весь рынок | Шорт после слома пампа +30%: цена ниже VWAP пампа, 2 из 3 признаков выдоха, цель — откат 70% пампа |
| Шортист пампов v1 | 15 мин, весь рынок | Шорт мелкой монеты после пампа +40%, когда памп выдыхается (объём, OI, фандинг, слом структуры) |
| Шортист листингов | 4 часа | Шорт фьючерсов возрастом 1–14 дней после провалившегося отскока к VWAP листинга |
| Охотник за повторными пампами | 1 день, спот | Покупка монет, которые уже пампились, у дна боковика; продажа на всплеске |
| Недельный моментум | раз в неделю | Лонг 3 лидеров и шорт 3 аутсайдеров по росту за 21 день среди топ-30 |

**Контрольная группа** — для сравнения: Супертренд, Охотник на скидки (RSI + Боллинджер), Ловец сквизов.

## Отчётность

- Нажми на бота — правила, статистика (профит-фактор, средняя прибыль/убыток, просадка), открытые сделки.
- Нажми на сделку — график: вход, выход, стоп, тейк, VWAP, RSI, открытый интерес; метрики на момент входа.
- **Журнал решений** — что бот увидел и почему вошёл или ПРОПУСТИЛ монету; каждое решение открывается на графике.
- **📋 Скопировать для обсуждения** — текст сделки или решения для чата с Claude.
- **📄 Скачать отчёт** — файл .md за 1/7/30 дней со всеми сделками и причинами пропусков.

## Плечо

У шортистов плечо 2x, у остальных 1x. Размер шортов считается от стопа (риск 1–1,5% капитала), плечо лишь уменьшает залог. Меняется в `config.py` → `LEVERAGE`.
Плечо 3x = позиция в 3 раза больше залога: прибыль и убыток ×3, ликвидация при движении цены ~33% против.
Симулятор честно считает ликвидацию — если цена дошла до неё, залог сделки сгорает.

## Честные условия

- Комиссия Bybit 0.055% на вход и на выход (считается от размера позиции, то есть с плечом больше).
- Проскальзывание: 0.03% на крупных монетах, 0.15% на мелких.
- Фандинг начисляется каждые 8 часов (шорты на пампах его обычно получают).
- Ни одна сделка не держится дольше месяца.

## Файлы

- `config.py` — настройки (баланс, комиссии, монеты).
- `bots/` — логика ботов. Новый бот = новый класс + строчка в `bots/__init__.py`.
- `core/` — движок: цены с Bybit, виртуальный брокер, база, страница результатов.

## Если что-то не так

- **«Нет связи с Bybit»** — проверь интернет. Если Bybit заблокирован у провайдера — включи VPN.
- **Сделок долго нет** — это нормально: боты ждут своих сигналов. Пампы на +40% бывают не каждый день.
- **Порт 8000 занят** — поменяй `DASHBOARD_PORT` в `config.py`.
